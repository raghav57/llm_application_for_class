# Session 11 – Step 2: Message Roles

## Project Overview

This exercise explores how different message roles influence the behaviour and responses of a Large Language Model.

We will use Ollama and Qwen3 1.7B to understand how messages are structured in conversational LLM applications.

## Learning Objectives

- Understand the concept of message roles.
- Understand system messages and user messages.
- Learn how system instructions influence model behaviour.
- Experiment with different system instructions.
- Compare LLM responses under different instructions.

## Technology Stack

- Python
- Ollama
- Qwen3 1.7B
